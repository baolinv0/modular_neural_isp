# S24 Capture–TM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. The user's ongoing task supplies the experiment objective; obtain accessible S24 inputs before claiming dataset or training execution.

**Goal:** 在已有物理模拟器和原 TM 上，完成 S24 静态代理数据、正确共同外观目标与 Apple/Samsung 各四组可复核实验。

**Architecture:** 显式 S24 来源审计与 scene 色彩/参考层连接已有 Bayer 采集；候选级无损 RAW 分片供固定前端与 TM 重算。AE读取完整过去预览，训练先渲染完整工作画布，以离散候选期望优化版本化质量代价；统计按源族聚合。

**Tech Stack:** Python、PyTorch FP32、NumPy、现有 OpenCV PNG16/JPG 解码、pytest；GPU可选、CPU诊断必需。

**Spec:** [S24_EXPERIMENT_PLAN.md](../../capture_tm/S24_EXPERIMENT_PLAN.md)。以下接口均为**拟新增**，并非当前代码API；步骤全未执行。

## Global Constraints

- 保留旧 scene-v1、采集-v2、checkpoint推理及旧J定义；新采集合同显式version3，不把旧数据默认为style-0。
- 只从 `denoised_raw_images` 导入静态内容代理，uint16三通道按RGB/65535解码；不二次减黑或逆gamma。
- per-scene `cam_illum`→WB、CCM用于同一scene所有候选/参考；物理传感器参数与色彩配置分开，默认不是S24校准。
- 同一源保留官方split与source-family；目标与有效区域不随候选、噪声或δ重定义。
- 默认工作长边pilot256/main512、AE长边128；工作H/W均偶数且≥12，按比例短边就近取偶数、平局取小；记录共同变换。完整画布计算全局预测器及LTM。原生crop/动态/学习融合后置。
- capture digital gain=1；快门/模拟增益改变采集，Apple补偿一次，Samsung virtual gain只在TM规定位置施加一次。
- train每源3个固定episode（δ0、source-key/seed2026确定的两个U[-2,+1]），val/test用{-2,0,+1}。train noise0/1、val10/11、test100/101/102/103；预览用独立命名seed域。不得给AE原JSON的GT-derived noise/SNR或δ。
- 新J3与规则/目标/预算配置在正式test前冻结；所有组使用同一源/预览/噪声/初始化与优化schedule。

## Review Focus

1. PNG16被PIL/普通imread降为8bit、BGR错序、stem配错或EXIF方向重复应用：Task1/2的真实编码fixture必须拒绝/检出。
2. 源族、style、δ或JPEG近重复跨split：Task1/7必须拒绝精确冲突、列出疑似冲突并按源族聚合。
3. 全局SensorProfile吞掉scene WB/CCM，或部署finish再次用单位色彩：Task2的不同色彩scene及checkpoint恢复测试覆盖。
4. GT/代价/规则/预览变化后复用旧缓存，或中断写入被当完整包：Task3/4/5的fingerprint和完成标记测试覆盖。
5. lazy/batch/chunk/GPU改变数学期望、数据schedule或AE看crop/未来：Task5/6的数值与因果性测试覆盖。

## 文件与共享类型

新增文件各保留单一职责，沿用 `capture_tm` 命名。共享dataclass放在 `capture_tm/scene_reference.py`，给 `Scene` 末尾加可选字段，避免破坏既有位置参数：

```python
SceneColorProfile(cam_illum: tuple[float, float, float],
                  ccm: tuple[tuple[float, float, float], ...], provenance: dict)
TargetSpec(kind: str, render_ev: float, target_sha256: str,
           geometry_sha256: str, reference_mask_sha256: str,
           pipeline_sha256: str, teacher_sha256: str | None = None)
ReferenceBundle(camera_reference: Tensor, target: Tensor,
                valid_reference_mask: Tensor, source_clip_indicator: Tensor,
                color_profile: SceneColorProfile, target_spec: TargetSpec,
                source_family_id: str)
```

图像CHW/float32；camera reference≥0、target在[0,1]；mask为bool[1,H,W]。`TargetSpec.kind`先只支持 `analytic`/`s24_style0`；frozen_teacher是后续模式，未实现时明确拒绝。schema中保存各变换/来源文件与hash；构造接口负责真实字段，不接受调用者仅设“verified=true”跳过检查。
