# TM algorithm library specification

The user authorizes implementing all five reviewed TM ideas in this repository with separate implementation agents, data loading, models, training, and independent review before delivery. This is an executable research library, not evidence of trained image-quality superiority. Base: main e0f82e9932b560a53a63d5eaf1a85ceefe4c91d3. Existing unrelated feature branches remain intact.

## Scope and architecture

Add `tm_library` alongside the original `photofinishing` package. Reuse original Gain/GTM/chroma/gamma networks and checkpoints; switch only the local operator. Keep the original baseline executable. Shared API supports A region curves, B bilateral spatial parameters, C bounded local EV residual, D synthetic-exposure Laplacian fusion, E edge-aware base/detail control. These are documented research implementations inspired by the reviewed mechanisms, not exact vendor reproductions.

All candidate operators consume gain-adjusted linear RGB `gain`, GTM RGB `base`, optional soft semantic channels and confidence, and return pre-chroma linear RGB plus diagnostic maps. Use float BCHW. Original photofinishing input is normalized linear sRGB [0,1]; it is not an arbitrary unbounded HDR radiance interface. Pre-TM gain values may exceed 1. Do not silently reinterpret sRGB or unaligned reference images as aligned linear inputs or GT.

## Stable interfaces

`tm_library.config.ModelConfig` dataclass: `algorithm` in baseline/region_curves/spatial_grid/gain_residual/exposure_fusion/base_detail; `semantic_mode` in none/train_only/explicit; `semantic_channels=3`; `width=16`; `analysis_size=64`; `curve_bins=16`; `num_experts=4`; `grid_size=8`; `grid_depth=8`; `max_ev=1.0`; `exposures=(-2.0,0.0,2.0)`; `pyramid_levels=3`; `filter_radius=3`; `filter_eps=0.01`; `use_3d_lut=False`; `freeze_backbone=False`; validate ranges and incompatible settings. Semantic channels are ordered person/skin/sky by default, may overlap, are probabilities [0,1], not RGB or exclusive class IDs.

Each operator class `RegionCurveOperator`, `SpatialGridOperator`, `GainResidualOperator`, `ExposureFusionOperator`, `BaseDetailOperator` is in its own module under `tm_library/operators/`, accepts `(config: ModelConfig)`, and implements `forward(gain, base, semantics=None, confidence=None) -> dict` containing `image` (B,3,H,W), `features` (B,width,h,w) for auxiliary supervision, and `maps` (dict of tensors). Inputs semantics are (B,S,H,W); confidence is (B,1,H,W). Zero confidence suppresses semantic conditioning, not necessarily image-based enhancement. All rendering must be differentiable, finite for black/white/tiny/odd images, and support batch>1.

`tm_library.common.ConditionEncoder(config)` implements forward with the same four arguments and returns width-channel low-resolution features. Absent masks become zero semantic channels, and confidence gates masks. Other common helpers: `luminance`, `apply_luminance(rgb,new_y,eps=1e-6)`, `monotonic_curves(logits)` (positive increments with 0/1 endpoints), `evaluate_curves(values,curves)` as documented by foundation implementation, edge-aware scalar upsampling, total variation. Each operator can implement algorithm-specific helper functions locally. No external pretrained-model downloads at import or test time.

Helper tensor contract: `monotonic_curves(logits)` converts (...,N-1) increments to (...,N) endpoint-including knots; `evaluate_curves(values,curves)` accepts (B,C,H,W) values and (B,K,N) curves and returns (B,K,C,H,W), using linear knot interpolation with normalized inputs. `guided_upsample(low,guide,radius=3,eps=0.01)` accepts BCHW low and B1HW full-resolution guide, returns BCHW at guide size. `tone_curve(x,a,b,c)` implements the upstream stable parametric curve with broadcasting. `total_variation(x)` returns scalar mean absolute spatial differences, including singleton dimensions safely.

`tm_library.model.TMModel(config)` reuses `PhotofinishingModule` submodules; `forward(image,semantics=None,confidence=None) -> dict` yields `output`, `linear`, `maps`, optional `semantic_logits`. For baseline+none, output equals upstream training-mode forward at fixed weights. S0 none never uses supplied masks; S1 train_only sends no masks to renderer and computes a semantic auxiliary head from renderer shared features only during training; S2 explicit conditions on supplied masks with confidence. Missing masks in S2 get zero conditioning. A missing-mask indicator in data distinguishes unlabelled samples from labelled background. Baseline supports none only, unless separately justified. Loading upstream weights is strict; library checkpoints carry config and state. `.to(device)` must also move upstream unregistered color-matrix tensors correctly.

## Operators

A: positive-increment monotonic curve bank; feature/semantic-conditioned normalized per-pixel weights; apply each shared RGB curve to pre-TM input and blend results. Report curves/weights. Do not assign fixed desired brightness per skin category.

B: condition on gain/base/semantic features, predict a coarse 3D bilateral grid of five coefficients (gate, three tone-curve parameters, local gain), learn a guidance map, trilinearly slice, and mix original GTM with local re-tonemapped gain input. Use upstream curve function or equivalent stable formula. Report grid/guidance/coefficients. Gate must allow the full [0,1] interval.

C: predict low-resolution log2 gain bounded by max_ev; guided upsample, apply to base RGB using a scalar per pixel. Report EV and gain. Initialize residual to zero. No unconstrained RGB additive residual.

D: generate fixed synthetic exposures from pre-TM input, predict normalized weights, form Laplacian image pyramids and Gaussian weight pyramids, blend per level, reconstruct. Report exposures/weights. Must genuinely use multiscale fusion, not just pointwise averaging. No claim of additional capture information or independent-noise reduction.

E: edge-aware base/detail decomposition of log luminance, predict base tone curve/control and separate detail gain, reconstruct luminance and RGB. Detail gains must change actual output; avoid algebraically cancelling decomposition with identical treatment. Include semantic conditioning for predicted controls; report base/detail/gain. Fixed initial filter is configurable, not claimed as full semantic-decomposition patent reproduction.

## Data and CLI

`tm_library.data.PairedImageDataset(manifest,image_size=None,augment=False,semantic_channels=3,require_target=True)` reads JSONL or JSON list (paths relative to manifest). Required keys id,input; supervised target plus `target_aligned:true`; optional semantics,confidence,metadata,reference,scene,camera,input_encoding. Input encodings linear_srgb/srgb/camera_rgb explicit. Camera RGB means demosaiced RGB plus metadata cam_illum/ccm, not Bayer DNG; conversion matches upstream green-normalized WB+CCM. Preserve PNG16/float precision. NPY supports CHW/HWC with explicit ambiguity errors; NPZ documented fixed key. Targets are sRGB [0,1]. Reject wrong channels, shape mismatch, nonfinite/range errors, duplicate IDs, unaligned target, missing files; never pair files by independent directory sort. Geometry transforms synchronized across input,target,masks,confidence. `semantic_valid` distinguishes missing annotation. Return tensors input,target,semantics,confidence,semantic_valid and strings id,scene,camera. References are never used as pixel targets. Inference permits absent target. S24-style manifest builder matches exact stems and records metadata/encoding. Synthetic generator provides deterministic distinct train/val fixtures with masks and known tone transforms.

Training CLI `python -m tm_library.train --config CONFIG [--resume CHECKPOINT]` uses train/val manifests, model config, original checkpoint optional, AdamW, finite losses, gradient clipping, scheduler, best/last checkpoint, deterministic seeds and resume of optimizer/scheduler/RNG. Supports all five operators and S0/S1/S2. Use aligned sRGB RGB L1, log-luma/gradient terms, optional region-balanced loss and S1 auxiliary BCE with valid mask; expose weights. Do not supervise missing semantic labels as negatives. Evaluate per sample then aggregate globally/by scene/camera/region; no test-based checkpoint selection. Inference CLI saves images and maps; no target/semantic leakage in S0/S1. Evaluation reports PSNR, SSIM, luma/region errors, clipping, latency (synchronized) and parameters with explicit measured scope. Portable configs for all algorithms, 3 semantic-mode examples, smoke command, Chinese usage and evidence boundaries.

## Verification

Tests cover operator mechanism/invariants/gradients, RGB/linear IO and uint16, metadata conversion, mask alignment and missing labels, original-baseline equivalence, actual optimizer updates for every algorithm, short loss-reduction probe, checkpoint resume/evaluation/inference roundtrip, S1/S0 inference independence from masks, S2 mask influence/zero confidence, and odd-size/black/white inputs. Execute on available CPU; no real dataset or GPU quality claims. Independent algorithm and integration reviewers inspect actual code after all implementations, followed by fixes and scoped re-review. Deliver a feature branch and draft PR without merging main.
