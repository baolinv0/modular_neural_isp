## Model and staged APIs

ModelConfig adds architecture_version=2, base_algorithm=None, correction_algorithm='none', correction_strength=1.0, correction_max_delta=0.25, correction_semantic_channel=None, post_mode='adaptive'. Existing algorithm remains the standalone selector when base_algorithm is None. Effective bases: baseline, gtm, region_curves, spatial_grid, gain_residual, exposure_fusion, base_detail. Correction choices none/region_curves/gain_residual only. A configured base_algorithm overrides only the default algorithm='baseline'; reject ambiguous nondefault selectors. correction strength [0,1], additive delta positive <=1; correction semantic channel must be valid and requires explicit semantic mode. Baseline/gtm without a learned candidate has no S1 auxiliary features: reject incompatible train_only. post_mode adaptive/fixed_reference; diagnostic training requires freeze_backbone=True.

Forward keeps existing positional image/semantics/confidence and adds keyword return_maps=True, correction_mask=None, correction_strength=None. Result contains output, linear, maps; semantic_logits only during S1 training. The correction anchor is the selected base's PRE-CHROMA linear result. Zero strength or zero ROI must preserve that anchor exactly. For semantic-gated correction, absent/zero-confidence semantics mean zero correction (main base still renders). Manual correction_mask is an explicit user control, distinct from semantic inference labels.

Foundation exposes staged methods with concrete contract documented in model.py: prepare_global(image); predict_controls(context, semantics=None, confidence=None, stage='base', anchor=None); render(context, controls, stage='base', anchor=None, correction_mask=None, correction_strength=None, return_maps=True); finish(linear, controls=None, return_maps=True). forward orchestrates the same stages, with exact staged/forward equivalence. Context carries gain and GTM plus original input; correction prediction occurs only after anchor is available. An original baseline can retain its upstream renderer as an explicitly unoptimized compatibility path. No fake hardware executor/thread wrapper.

Every A–E operator adds predict(gain,base,semantics=None,confidence=None) -> controls (dict with features), render(gain,base,controls,return_maps=True) -> {image,features,maps}, with forward calling predict then render. predict consumes images at any size through ConditionEncoder; it must only run learned feature CNN at configured analysis_size. B render may execute a cheap RGB affine guide, never expanded width-channel CNN. return_maps=False yields empty diagnostic maps; models/CLIs must propagate it.

ConditionEncoder downsamples gain, base and gated semantic inputs BEFORE concatenation, avoiding full-resolution 9-channel concatenation. It accepts semantic maps/confidence at matching separate low resolution and resizes them to analysis resolution; validate batch/channel/domain. Missing semantics are allocated only at analysis size. Gate probabilities BEFORE spatial reduction. Reduction is antialiased/area where appropriate; preserve arbitrary odd/tiny dimensions and mixed dtypes/devices. S0/S1 ignore semantic inputs as before.

post_mode=fixed_reference derives downstream LUT/gamma controls from the same frozen original LTM reference for every candidate; applies those cached controls to the candidate, with original neural backbone frozen. Shared controls must actually be identical across candidate perturbations. Adaptive remains full rendering mode. Report raw linear-stage errors alongside display metrics. Do not claim freezing weights alone fixes image-dependent chroma/gamma controls.

Architecture change must be explicit: new library checkpoint format tm_library_v2 and architecture_version=2. Reject v1 library checkpoints with an actionable migration/retraining explanation rather than silently reinterpret A/B/E weights. Original bare photofinishing checkpoints remain loadable strictly. Adjust existing tests for changed v2 architecture, retaining invariants and original baseline forward equality.

## Operators

A standalone: use monotonic shoulder coordinate u=x/(1+x) for nonnegative gain before curve lookup, preserving distinctions above1. Existing learnable shared bank is a documented variant, not per-image curve prediction. Evaluate experts sequentially/accumulate to avoid K full RGB images and K full int64 lookup indices; low-res weight logits may become scalar full-res expert weights. A correction: model blends a bounded (candidate-anchor) delta with correction strength/ROI; no requirement for random initial curves to be identity, but explicit zero control is exact. Candidate is rendered on anchor domain (pass anchor as both gain/base to A correction predict/render), not original gain. C correction retains scalar bounded EV and applies gated EV before exp2, preserving chromaticity pre-postprocessing. Standalone C continues GTM-only anchor, clearly named/documented.

B: real 3D grid and five parameter controls retained. Replace full_features upsampling/width-channel guide with a learnable cheap affine guide from gain/base RGB (6->1) or a scalar luminance guide. No full-resolution width-channel feature allocations. Test guidance/grid gradients and memory-shape hooks. Shared explicit stage API.

D: retain real Gaussian/Laplacian fusion and configurable exposures/scales. Shared stage API; avoid diagnostics retention when disabled. Keep inherent multiscale cost explicit; this is not claimed as a cheap fixed-function ISP renderer.

E: base contrast/shift become spatial low-resolution predictions, edge-aware upsampled, allowing same-luminance different semantic regions to receive different base exposure. Detail gain remains independently controlled. Retain tests proving detail decomposition does not cancel, finite extremes and no fixed skin brightness targets. Filter radius remains explicit in input pixels; document resolution dependence.

## Pretrained segmentation adapter

New semantics.py: SegmentationConfig, SemanticProvider, apply_semantic_provider(batch, provider, semantic_mode, training). Final exact signatures announced to integration worker before use.

Backends none, torchscript, factory. No downloads or opaque zero-mask fake model. TorchScript loads the user's checkpoint; factory uses explicit local module:function + kwargs to construct architecture, then strictly loads a tensor state_dict (optional nested key), never torch.load of an arbitrary full model object. Support tensor, configured dict key, or configured tuple index outputs. Modes softmax_logits/sigmoid_logits/probabilities, explicit channel groups mapping model output channels into ordered TM semantic channels. Validate output dimensions/probabilities and finite values. Preprocessing explicitly declares `linear_srgb`/`srgb` input, resize, mean/std and model input size. Return soft semantics/confidence at model analysis resolution (confidence may be B1HW or per-channel BCHW); full masks can be aligned for loss/metrics by integration adapter. Frozen eval/no-grad segmentation parameters are excluded from optimizer.

Source policy model/manifest/prefer_manifest, default manifest. S0 never invokes provider. S1 invokes provider for training auxiliary labels only; evaluation/inference must not load or require its checkpoint. S2 invokes provider in train/val/infer when configured, supplying soft masks/confidence. Manual valid annotations can override model pseudo-labels under prefer_manifest; validity is annotation supervision validity, confidence is runtime trust; do not conflate undocumented meanings. Confidence-weight pseudo-supervision numerators while normalizing by available-label mass, so uniformly low trust reduces absolute auxiliary strength; preserve missing-label zero loss. Record preprocessing/class mapping/source config in checkpoints; external model weights remain external. CLI can override semantic config/path for S2 deployment. Test an actual saved and reloaded tiny TorchScript/factory fixture, no production-quality claims.
