# 工程回传入口

**默认只需一份 Markdown 文档，填写后复制粘贴正文回传。**

请使用 [单文件报告模板（v2）](REPORT_SINGLE_FILE_TEMPLATE.md)。已有 REPORT 可按模板补齐，不必重写或重训。

这份模板将训练配置、结构差异、评估协议、结果、配对差值、已有 seed 复跑、成本和关键案例文字说明放在同一文件中。无需另交 CSV、图片、权重或日志包；未测写 not_run，无法恢复写 unknown。服务器路径仅用于工程侧追踪，不代替文档内的实际数值或说明。

小型外部集（例如现有 21 张）建议直接粘贴完整逐图差值表；大数据集使用配对差值摘要。没有图像/源码原件时，分析结论会明确限于报告证据。

## 历史多文件模板（可选）

[原报告模板](REPORT_TEMPLATE.md)、8 张 CSV、[字段字典](DATA_DICTIONARY.md) 和 protocol_template.json 保留，供工程端内部归档使用，不作为用户回传要求。原文件内容中的多文件交付清单不适用于单文件回传方式。
